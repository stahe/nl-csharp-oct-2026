    15. Bijlagen

    15.1. DBMS en MySQL met Laragon

    In 2008 beschreven de bijlagen van de cursus de installatie van SQL Server 2005 Express en MySQL 5, hun beheertools (MySQL GUI Tools) en hun ODBC-stuurprogramma's, met een dertigtal schermafbeeldingen. De hoofdstukken 10 en 11 van dit document gebruiken uitsluitend MySQL 8, en de eenvoudigste manier om dit onder Windows te installeren is het installeren van Laragon, een draagbare ontwikkelomgeving die onder meer MySQL, de grafische client HeidiSQL, een voorgeconfigureerde terminal, Apache en PHP bevat. De auteur gebruikt het ook voor zijn PHP-cursussen.

    15.1.1. Installatie

    Laragon kan worden gedownload van https://laragon.org. De installatie is standaard; u kunt de voorgestelde installatiemap ([C:\laragon]) behouden. Laragon levert MySQL 8 (de exacte versie hangt af van de versie van Laragon), met een beheerdersaccount zonder wachtwoord ([root]) en een server die luistert op poort 3306 op de lokale machine. Dit is de configuratie die de voorbeelden in dit document veronderstellen, waarin de connectiestrings de volgende vorm hebben:

    1
    Server=localhost;Port=3306;Database=dbarticles;User=root;Password=

    Als MySQL op een andere manier is geïnstalleerd, met een wachtwoord voor [root], moet u dit invullen na [Password=] in de connectiestrings van de voorbeelden (de bestanden [appsettings.json] of constanten bovenaan de programma's).

    Voor een systeem zonder Laragon kunt u ook MySQL Community Server installeren vanaf https://dev.mysql.com/downloads/mysql/, of de opensourcevariant ervan, MariaDB. De voorbeelden zijn echter alleen met MySQL 8 getest: de scripts in Hoofdstuk 10 gebruiken een collatie die specifiek is voor MySQL 8 ([utf8mb4_0900_ai_ci]), en de voorbeelden in Hoofdstuk 11 geven een MySQL-serverversie ([MySqlServerVersion]) door aan Pomelo; met MariaDB zouden deze twee punten moeten worden aangepast.

    15.1.2. MySQL starten en stoppen

    Het hoofdvenster van Laragon bevat een knop „Start All” die de servers (Apache en MySQL) start en een knop „Stop” die ze stopt. In tegenstelling tot de MySQL 5-installatie uit 2008 is MySQL geen Windows-service die bij het opstarten van het systeem wordt gestart: het draait alleen wanneer het vanuit Laragon is gestart, waardoor het geen middelen verbruikt wanneer het niet wordt gebruikt. Via het menu van Laragon (klik met de rechtermuisknop in het venster) kunt u ook alleen MySQL starten en de versie ervan kiezen.

    Wanneer MySQL niet draait, mislukken de programma's uit de hoofdstukken 10 en 11 met een uitzondering die aangeeft dat er geen verbinding kon worden gemaakt („Unable to connect to any of the specified MySQL hosts”): dit is het eerste wat u moet controleren als er een fout optreedt.

    15.1.3. De opdrachtregelclient

    Met de knop Terminal in Laragon opent u een terminal waarin de opdrachten van Laragon beschikbaar zijn, waaronder de MySQL-opdrachtregelclient [mysql]. Om verbinding te maken met de server gebruikt u:

    1
    > mysql -u root

    voer vervolgens SQL-opdrachten in die eindigen met een puntkomma ([show databases;], [use dbarticles;], [select * from articles;]) en [exit] om af te sluiten. De client kan ook een SQL-script uitvoeren, wat Hoofdstuk 10 doet om zijn databases aan te maken:

    1
2
3
    > cd csharp-oct-2026\10-adonet\sql
> mysql -u root < dbarticles.sql
> mysql -u root < dbtaxes.sql

    De scripts maken hun database telkens volledig opnieuw aan: u kunt ze opnieuw uitvoeren om na het testen de gegevens in de beginstaat te herstellen.

    15.1.4. De grafische client HeidiSQL

    Met de knop Database in Laragon start u de grafische client HeidiSQL, die de MySQL GUI Tools uit 2008 vervangt (inmiddels verouderd). Bij de eerste start biedt HeidiSQL een verbindingssessie aan die al is geconfigureerd voor de MySQL-server van Laragon (host [127.0.0.1], gebruiker [root], leeg wachtwoord, poort 3306); open deze eenvoudig. U ziet:

    • links de boomstructuur van de databases van de server en hun tabellen;
    • rechts tabbladen met de structuur van een tabel, de gegevens ervan (die rechtstreeks kunnen worden bewerkt) en een veld voor het invoeren van SQL-query's (het tabblad „Query”), die worden uitgevoerd met [F9].

    Om een database aan te maken met een script uit Hoofdstuk 10 opent u het script (via het menu „File”, met de opdracht „Load SQL file”) in een querytabblad en voert u het vervolgens uit ([F9]). U kunt ook een database, een gebruiker en gebruikersrechten aanmaken via de menu's van HeidiSQL (rechtsklikken op de verbinding / „Create New” / „Database”; menu „Tools” / „User Manager”), maar de SQL-scripts hebben het voordeel dat ze reproduceerbaar zijn en opnieuw kunnen worden uitgevoerd.
